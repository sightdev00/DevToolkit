# Model tools

这里保存与模型文件、模型制品和部署工具链有关的通用开发工具。

## 当前入口

### [`python-model-tools/`](python-model-tools/)

面向 ONNX、RKNN 及相关模型格式的 Python 工具索引与使用决策指南。它记录：

- 官方仓库与安装来源；
- 模型格式、平台和核心职责；
- 当前维护状态与已核查版本；
- 推荐使用条件、替代关系和验证要求；
- RKNPU1、RKNPU2 等不兼容工具链的边界。

索引不保存第三方 wheel、SDK、模型权重或项目虚拟环境。

## 与 vision-workbench 的边界

`DevToolkit/model/` 负责可复用的确定性工具、工具索引和工具使用边界。

`vision-workbench` 负责：

- 模型架构、任务和算法机制；
- ONNX 到芯片模型的实际转换实验；
- PC 与板端精度对齐；
- 量化、算子支持和性能诊断；
- 具体硬件、SDK 和模型版本形成的工程结论。

工具能成功执行，不代表模型语义、精度、性能或产品行为已经通过验收。

## 收录标准

模型工具进入这里前，应满足至少一项：

1. 可以跨模型项目复用；
2. 能检查、转换、简化、运行、比较或验证模型制品；
3. 能降低模型工具链选择和兼容性判断成本；
4. 能提供确定性输入输出，并具有明确失败模式。

以下内容不收录：

- 项目专用转换命令和硬编码路径；
- 训练框架的一般教程；
- 未经核查的第三方脚本列表；
- SDK、wheel、模型文件和客户制品；
- 用工具运行成功代替精度验证的流程。
